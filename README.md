# АЛКО НОЧЬ — сайт для домена 24alkomoscow.site

Статический сайт (HTML + CSS + JS, без сборщиков и сервера), перенесённый из папки `site1`
(«АЛКО НОЧЬ») репозитория `tengizkaa-coder/oskar`, ветка `arena/f9bb91dc-oskar`.
Дизайн, цвета, логотип и название сохранены: те же CSS-файлы и та же разметка карточек,
категорий, доставки и вопросов. `site-previews/` и `img/` больше не внешние зависимости —
всё лежит внутри этого репозитория.

## Корзина — это список, а не отправка заказа

Корзина хранится в `localStorage` браузера (`selection-alkonoch-v1`), переживает переходы
между страницами и не отправляет данные ни на сервер, ни в Telegram. Кнопка оформления —
обычная ссылка на звонок. Заказ подтверждает оператор по телефону.

## Цены и объёмы

Цен на сайте нет вообще — везде «В наличии · цену уточняйте по телефону».
В `Offer` в JSON-LD цены тоже нет (проверяется `tools/check.py`).
Объёмы взяты из исходного каталога (`tools/data/products.json`) и по фотографиям не проверялись;
на странице товара об этом есть пометка. Сроки и стоимость доставки нигде не указаны.

## Ограничения доступа

`assets/js/gate.js` (копия логики основного сайта «АЛКО МСК»):

| Посетитель | Результат |
| --- | --- |
| Поисковый робот (Googlebot, YandexBot, Bingbot и др. по user-agent) | доступ открыт |
| Телефон + переход из Google / Яндекса / Bing / DuckDuckGo / Mail.ru | доступ открыт, вход запоминается в `sessionStorage` на эту вкладку |
| Телефон + внутренний переход после такого входа | доступ открыт |
| Телефон + прямой вход (без поискового реферера) | белый экран с текстом «Ошибка загрузки страницы.» |
| Компьютер (десктоп) + любой вход | **белый экран без текста** |
| `/test/`, `/test.html` — любое устройство | доступ открыт, страницы `noindex,nofollow` |

Проверка выполняется на клиенте в браузере. Это **не защита файлов и не пароль**:
user-agent и `Referer` легко подделать, а живой посетитель без реферера (например, из
мессенджера или по прямому домену) увидит белый экран. Ограничения также мешают SEO и
переходам из соцсетей, закладок и рекламы — индексироваться будут только обходы роботов.

Практические следствия, о которых нужно знать:

- iPhone Safari с включённым «Предотвращать перекрёстное отслеживание» может не передавать
  `Referer` от Google → посетитель увидит «Ошибку загрузки страницы», хотя пришёл из поиска.
- Открытие внутренней ссылки в новой вкладке сбрасывает `sessionStorage` → в новой вкладке
  снова белый экран. В текущей вкладке переходы работают.
- Заблокированный компьютерный посетитель не увидит ничего (белый экран) — так и задумано,
  но диагностировать такую жалобу сложно: проверяйте с телефона и с `/test/`.
Снимаются они осознанно: удалите в `tools/build.py` строку с `<script src=…gate.js>` и
`gate.css` из шаблона `page()` и пересоберите сайт, либо просто удалите `assets/js/gate.js`
(тогда скрипт не загрузится, страницы откроются всем).

## Структурированные данные

- Главная: `WebSite` + `Store` (название, URL, логотип, телефон, Telegram, зона «Москва»,
  круглосуточный график, каталог категорий).
- Каталог и категории: `CollectionPage` + `ItemList` + `BreadcrumbList`.
- Товары: `Product` + `Offer` (`availability: InStock`, без `price`) + `BreadcrumbList`.
- Вопросы: `FAQPage`.
- Адрес физической точки **не указан**: для нового бренда он не подтверждён, и на страницах
  адреса нет. Если подтвердите — впишите его в `STORE_ADDRESS` в `tools/site_config.py`
  и пересоберите сайт.

## Локальный просмотр

```bash
python3 tools/preview-server.py 8000   # «/» перенаправляет на «/test/» — удобно для просмотра
# рабочие страницы как есть: http://127.0.0.1:8000/index.html

# тестовый просмотр без ограничений: http://127.0.0.1:8000/test/

```

## Пересборка и правка контента

```bash
python3 tools/build.py                 # домен берётся из tools/site_config.py
python3 tools/build.py --domain https://new-domain.ru
python3 tools/check.py                 # ссылки, canonical, robots, sitemap, JSON-LD
```

Все телефоны, названия, категории, округа, FAQ и домен — в `tools/site_config.py`.
Товары — в `tools/data/products.json` (`[категория, название, объём, путь к фото]`).
После правки данных запустите `build.py`, он обновит страницы, `products.js`, `sitemap.xml`,
`robots.txt` и `CNAME`.

## Публикация: пошагово

### 1. Влить ветку в `main`

```bash
git checkout main && git merge --ff-only arena/990c5ed0-oscar-1 && git push origin main
```

(или создать pull request и нажать Merge в GitHub).

### 2. Включить GitHub Pages

1. Откройте репозиторий `tengizkaa-coder/OSCAR-1` → **Settings** → **Pages**.
2. **Build and deployment → Source**: *Deploy from a branch*.
3. **Branch**: `main`, папка **`/ (root)`** → **Save**.
4. Через 1–3 минуты сайт появится по адресу `https://tengizkaa-coder.github.io/OSCAR-1/`
   (файл `CNAME` уже лежит в корне, поэтому Pages сразу предложит домен `24alkomoscow.site`).

### 3. Подключить домен `24alkomoscow.site`

**Settings → Pages → Custom domain**: впишите `24alkomoscow.site` → **Save** → дождитесь
проверки DNS → включите **Enforce HTTPS**.

DNS у регистратора домена:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153` |
| CNAME | `www` | `tengizkaa-coder.github.io` |

Значения A/AAAA — официальные адреса GitHub Pages. DNS обновляется от нескольких минут до 24 часов.

> В задаче домен указан как `http://24alkomoscow.site/`. Canonical, sitemap и `CNAME` собраны
> под **https://24alkomoscow.site** — после включения «Enforce HTTPS» адрес будет именно таким.
> Если HTTPS включить не удастся, скажите — пересоберу сайт под `http://` (это плохо для SEO,
> но технически возможно).

### 4. После публикации — проверить, а не предполагать

```bash
curl -I https://24alkomoscow.site/            # 200, HTTPS
curl -s https://24alkomoscow.site/robots.txt
curl -s https://24alkomoscow.site/sitemap.xml | head
```

Затем добавьте сайт в **Google Search Console** и **Яндекс.Вебмастер**, подтвердите домен и
отправьте `https://24alkomoscow.site/sitemap.xml`. Тестовые страницы в карту не входят.
Индексация не мгновенная и не гарантирована — по факту её видно только в этих панелях.

### 5. Если сайт будет жить не в корне домена

Все ссылки относительные, поэтому сайт работает и в подпапке (`…github.io/OSCAR-1/`).
Но canonical, `sitemap.xml` и `robots.txt` будут указывать на `24alkomoscow.site` — при
переезде на другой адрес просто запустите `python3 tools/build.py --domain https://новый-домен.ru`.
