# АЛКО НОЧЬ — сайт для домена 24alkomoscow.site

Статический сайт (HTML + CSS + JS без сборщиков и сервера) для магазина «АЛКО НОЧЬ».
Последняя переделка: структура и анатомия страниц повторяют референс
`alcodostavkaplanet.msk.ru` — витрина с полками, сетка категорий, карточки с «В наличии»,
страница товара с блоком «С этим товаром также покупают», липкая корзина, полоса преимуществ,
SEO-текст внизу главной. Контент при этом свой: бренд, логотип, телефон, Telegram, 30 товаров
с фотографиями. Цены не публикуются (см. ниже), поэтому вместо числа в карточке стоит
«Цену уточняйте» и кнопка звонка.

## Структура

| Раздел | Адреса |
| --- | --- |
| Главная | `/` |
| Каталог (все 30 позиций, поиск, фильтр, корзина) | `/catalog/` |
| 10 разделов каталога | `/catalog/whisky/`, `/vodka/`, `/gin/`, `/cognac/`, `/liqueur/`, `/vermouth/`, `/white-wine/`, `/red-wine/`, `/sparkling/`, `/beer/` |
| 30 страниц товаров | `/catalog/product/<товар>/` |
| Доставка + 12 округов Москвы | `/delivery/`, `/delivery/<округ>/` |
| Вопросы и ответы | `/faq/` |
| Тестовый просмотр (весь сайт целиком) | `/test/`, `/test/catalog/`, … |
| Служебное | `404.html`, `test.html` (переход в `/test/`) |

Всего **56 рабочих страниц** и столько же в `/test/`. Все ссылки относительные, поэтому сайт
работает и в корне домена, и в подпапке вида `…github.io/OSCAR-1/`.

## Анатомия страниц

**Главная**: тёмная полоса с телефоном и Telegram → шапка (лого, меню, телефон, корзина) →
герой с тремя бутылками и кнопками «Открыть каталог» / «Позвонить» → полка 10 категорий с
иконками → полка «Крепкий алкоголь» (18 позиций) → полка «Вино, игристое и пиво» (12) → три
преимущества → зелёная полоса «Не нашли нужный напиток?» → SEO-текст с округами и ссылками →
подвал. На телефоне снизу липкая панель «Позвонить» + «Корзина».

**Раздел каталога**: H1 + описание + счётчик позиций и статус «В наличии» → поиск → сетка
карточек → «Как выбрать» → ссылки на другие разделы.

**Товар**: хлебные крошки → большое фото + чипы «раздел / объём / в наличии» → H1 → блок цены
(«Цену уточняйте» + телефон) → количество, «В корзину», «Позвонить» → ссылки на Telegram и
раздел → примечание об объёмах → полка «С этим товаром также покупают» (5 карточек).

**Доставка**: шаги заказа, что уточняет оператор, оплата (без выдуманных способов), плитка
12 округов. **Округ**: условия по адресу + плитка остальных. **Вопросы**: аккордеон из FAQ.

## Файлы

```
assets/css/site.css        весь дизайн: токены, компоненты, адаптив (один файл)
assets/js/site.js          корзина, полки с прокруткой, мобильное меню, поиск
assets/js/products.js      данные каталога для корзины (генерируется сборкой)
img/                       30 фотографий товаров (PNG с прозрачным фоном)
logo.svg, favicon.ico      логотип и иконка
tools/build.py             сборка обоих деревьев страниц
tools/check.py             краулер: ссылки, SEO, schema.org, sitemap
tools/behavior-test.js     поведенческие тесты (jsdom)
tools/preview-server.py    локальный сервер: / — рабочая главная, /test/ — тест
tools/site_config.py       бренд, телефон, Telegram, категории, округа, FAQ, аналитика
tools/data/products.json   [категория, название, объём, фото]
```

Палитра: тёмно-зелёный `#0c1a12`, акцент `#17a05a`, фон `#f6f7f4`, карточки белые,
шрифты Manrope (текст) и Unbounded (логотип). Тема одна — переключателей дизайна больше нет.

## Сборка и правки

```bash
python3 tools/build.py                     # домен из tools/site_config.py
python3 tools/build.py --domain https://new-domain.ru
python3 tools/check.py                     # ссылки, SEO, schema.org, sitemap
python3 tools/preview-server.py 8100       # локальный просмотр на 0.0.0.0:8100
```

Контент меняется в `tools/site_config.py` и `tools/data/products.json`, после чего сайт
пересобирается. Каталог, полки, карточки и страницы товаров отрисованы **статически в HTML**:
без JavaScript видны все товары, категории и ссылки. Скрипт только добавляет корзину,
прокрутку полок и поиск.

## Проверки

`python3 tools/check.py` — обход 163 страниц по двум деревьям:

- ни одной битой ссылки, страницы не выходят за пределы своего дерева, из рабочего дерева нет
  ссылок в `/test/`;
- на каждой странице ровно один `H1`, title, description 60–200 символов, `canonical` =
  адрес на домене, `robots` рабочие `index,follow`, тестовые `noindex`;
- на главной две полки, 10 категорий, 3 преимущества, 3 бутылки в герое, ≥20 карточек;
  в каталоге 30 карточек, в разделах — по 5/4/2/3/2/2/3/3/3/3;
- на сайте **нет цен** (ни `₽`, ни «руб.»), нет остатков скрипта ограничения доступа;
- `sitemap.xml` — ровно 56 рабочих адресов, `robots.txt` закрывает `/test/`, `CNAME` совпадает
  с доменом.

`tools/behavior-test.js` — **51 проверка** в jsdom: главная открыта на десктопе, телефоне и
ботам; 10 категорий, две полки, 28 карточек; корзина (счётчик, `localStorage`, панель,
«+/−», сохранение между загрузками, `tel:` при оформлении, отсутствие формы заказа);
страница товара (H1, «Цену уточняйте», 5 карточек в блоке «покупают»); раздел каталога;
поиск «jack» → 1 карточка, пустой результат → подсказка, сброс; фильтр «Джин» → 2 товара;
мобильное меню; `/test/` (noindex, без canonical, ссылки не уводят из теста, отдельная корзина).

```bash
python3 -m http.server 8000 --bind 127.0.0.1
cd /tmp && mkdir sitetest && cd sitetest && npm init -y && npm i jsdom@24
cp <repo>/tools/behavior-test.js . && BASE=http://127.0.0.1:8000 node behavior-test.js
```

## Корзина и цены

- Корзина — список в `localStorage` (`selection-alkonoch-v1`), переживает переходы между
  страницами, **никуда не отправляется**; кнопка «Оформить — позвонить» открывает звонок.
  У `/test/` отдельная корзина (`selection-alkonoch-test-v1`).
- Цен нет нигде: ни в карточках, ни в `Offer` (проверяется автоматически). В карточке стоит
  «Цену уточняйте» и подпись «по телефону +7 (495) 095-95-99». Как только появится прайс —
  его нужно добавить в `products.json`, в разметку карточки и в `Offer` (поле `price`).

## Доступ

Ограничения сняты **по решению владельца**: сайт открыт всем — с телефона, с компьютера, из
поиска, из мессенджеров. Никакого белого экрана, `gate.js` удалён.

Файлы `noindex` не содержат, кроме служебных и тестовых: `/test/` (`noindex,nofollow`),
`test.html`, `404.html`. `robots.txt` закрывает `/test/` от обхода.

## SEO

- `canonical` на каждой странице — абсолютный адрес на `https://24alkomoscow.site`.
- `sitemap.xml` — 56 рабочих адресов, тестовых нет.
- `robots.txt` — `Allow: /`, `Disallow: /test/`, `Disallow: /test.html`, ссылка на sitemap.
- JSON-LD: `Store` (телефон, часы, зона, каталог разделов), `WebSite`, `BreadcrumbList`,
  `CollectionPage`, `ItemList`, `Product` + `Offer` **без `price`**, `FAQPage`.
- Адреса магазина нет: физическая точка не подтверждена, поэтому в `Store` нет `address`.
- Счётчики Метрики/GA4 подключаются только при заполненных `YANDEX_METRIKA_ID` / `GA4_ID` в
  `tools/site_config.py` и только на рабочих страницах.

## Публикация

1. `git push` в ветку, из которой публикует GitHub Pages.
2. Settings → Pages: Source = «Deploy from a branch», Branch = эта ветка, папка `/ (root)`.
3. `CNAME` в репозитории содержит `24alkomoscow.site`, DNS: A-записи `185.199.108.153`,
   `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, `www` → CNAME на
   `tengizkaa-coder.github.io`.
4. После деплоя отправить `https://24alkomoscow.site/sitemap.xml` в Google Search Console и
   Яндекс.Вебмастер — до этого индексацию нельзя считать подтверждённой.

## Что осталось за кадром (честно)

- **Цены.** На референсе они есть, здесь их нет: чужие цифры нельзя выдавать за свои.
  Для карточек с ценой нужен ваш прайс.
- **Сроки и стоимость доставки.** «За 30 минут», «690 ₽ по МКАД», «минимум 990 ₽» с
  референса не переносились: это их условия, а не ваши. Везде сказано «уточнит оператор».
- **Приложение и 15% скидка.** У референса промо-полоса с App Store и Google Play — у вас
  приложения нет, поэтому полосы нет.
- **Дизайн.** Структура, блоки и поведение повторяют референс, но палитра, шрифты и вёрстка
  свои: CSS и скриншоты их сайта недоступны, копировать пиксель в пиксель было не из чего.
- **Объёмы.** Взяты из исходного каталога и по фотографиям не проверялись — об этом сказано
  на страницах товара.
